## 💻 Projetos em destaque

### 🛒 [Saga E-Commerce — Microsserviços](https://github.com/nynaromanoff/saga-ecommerce)

Projeto de e-commerce em desenvolvimento, com arquitetura distribuída e integração entre serviços de catálogo, estoque, pedidos e pagamentos.

**Tecnologias e conceitos:**
- Java e Spring Boot
- RabbitMQ e comunicação assíncrona
- Arquitetura de microsserviços
- Padrão SAGA coreografada
- PostgreSQL e AWS S3
- Integração com Stripe
- Observabilidade com Prometheus e Grafana

O objetivo é explorar a integração entre serviços independentes, o tratamento de falhas e a consistência dos processos de compra.

### ⚙️ [File Processor — Processamento Assíncrono](https://github.com/nynaromanoff/file-processor)

API voltada ao processamento assíncrono de arquivos, com foco em eficiência, desacoplamento e resiliência.

**Tecnologias e conceitos:**
- Java 21 e Spring Boot
- PostgreSQL
- AWS S3 e SQS
- Docker e LocalStack
- Processamento em fluxo (*streaming*)
- Retentativas e Dead Letter Queue (DLQ)

O projeto explora estratégias para processar arquivos grandes sem sobrecarregar a aplicação e para lidar com falhas no processamento.

### 🧩 [Microservices with Spring Cloud](https://github.com/nynaromanoff/microservices-with-spring-cloud)

Projeto de estudos voltado à construção de aplicações com microsserviços, explorando ferramentas do ecossistema Spring Cloud, Docker e Kubernetes.

[Ver repositório](https://github.com/nynaromanoff/microservices-with-spring-cloud)
